# Powering Potential dashboard

Live: https://wilsonck75.github.io/projects/powering-potential-dashboard/

This bundle is published from the source project at
[D-Cubed-Data-Lab/powering-potential-dashboard](https://github.com/wilsonck75/D-Cubed-Data-Lab/tree/main/powering-potential-dashboard).
When the source project changes, re-copy its generated files here (`index.html`,
`program-data.js`, `dashboard-data.js`, `data/`) to publish the update.

- **Program** is the default view: Karatu 23, canonical school list, activity types from AJ's Key tab.
- **Workbench** is the previous archive-quality dashboard.
- Rebuild data with `python3 build_program_data.py && python3 assemble_index.py` (run in the source
  repo, then copy the regenerated files here).
